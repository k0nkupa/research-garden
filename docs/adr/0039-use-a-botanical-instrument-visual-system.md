# Use a Botanical Instrument visual system

Research Garden uses a cool mineral canvas (`#EDF3EE`), deep bark ink (`#21332B`), canopy green (`#3C6B53`), lichen (`#9CB29B`), pollen (`#D6A63A`), and mulberry uncertainty (`#7A4E64`). Literata carries reading and titles, Instrument Sans carries controls, and IBM Plex Mono carries evidence metadata; the signature interaction illuminates a selected Claim or Harvest's complete path to its Roots.
